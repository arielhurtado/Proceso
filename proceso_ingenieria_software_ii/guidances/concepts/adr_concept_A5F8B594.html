Main Description

Cada ADR documenta: Titulo, Contexto, Decision, Consecuencias. Se almacena en /docs/adr/ del repositorio. Ejemplo: "ADR-001: Usar PostgreSQL como base de datos principal". Vinculado a las historias que lo motivaron.
