Main Description
  • Clases: modelar el dominio o el diseno detallado de un componente (nivel 4 de C4).
  • Secuencia: flujos complejos entre componentes/objetos en una historia critica.
  • Estados: entidades con ciclo de vida no trivial (ej. Pedido: Creado -> Pagado -> Enviado -> Entregado).

No es necesario diagramar todo. Solo las partes no obvias o criticas para el negocio.
