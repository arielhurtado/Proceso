Main Description
  • Clases de prueba terminan en *Test.
  • Metodos con @Test y nombre descriptivo (shouldThrowExceptionWhenAmountIsNegative).
  • Usar @BeforeEach para setup; @AfterEach para cleanup.
  • Assertions: assertEquals, assertThrows, assertTrue.
  • Cobertura minima acordada en la DoD (ej. >80% en logica de negocio).
