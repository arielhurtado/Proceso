Main Description

Nivel 1 - Contexto: el sistema como caja negra y sus actores/usuarios externos.

Nivel 2 - Contenedores: apps web, APIs, bases de datos, microservicios. Tecnologia y protocolos.

Nivel 3 - Componentes: descomposicion de un contenedor en componentes logicos y sus responsabilidades.

Nivel 4 - Codigo: diagramas UML de clases para componentes criticos o complejos.

Usar C4 para comunicacion de alto nivel; UML para detalle de diseno. Diagramas versionados como codigo.
