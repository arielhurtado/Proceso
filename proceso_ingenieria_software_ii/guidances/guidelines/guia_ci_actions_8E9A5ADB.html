Main Description

Workflow minimo (.github/workflows/ci.yml):

  • on: push / pull_request sobre main.
  • jobs.build: setup JDK, cache de dependencias, ./gradlew test (o mvn test), publicar reporte de cobertura.
  • Estado visible en el README (badge) y en el Information Radiator.
