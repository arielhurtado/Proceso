Task: Evolucion Arquitectonica por Sprint
Identificar y ejecutar cambios arquitectonicos dentro del Sprint.
Disciplines: Arquitectura
Purpose
Mantener la arquitectura alineada con el codigo sin caer en Big Design Up Front.
Relationships
RolesPrimary Performer:
  • Arquitecto
Additional Performers:
  • Equipo de Desarrollo
InputsMandatory:
  • Product Backlog
    		Optional:
    • Software Architecture Document (SAD)
      Outputs
      • Architecture Decision Records (ADRs)
      • Diagramas C4 (como codigo)
      • Software Architecture Document (SAD)
        Main Description

        Durante el Sprint Planning, identificar historias con impacto arquitectonico. Si es necesario, crear una tarea de Spike Arquitectonico (timeboxed, ej. 1 dia) para explorar alternativas. Las decisiones se registran como ADR. Al final del Sprint, el SAD refleja el estado real de la arquitectura.
