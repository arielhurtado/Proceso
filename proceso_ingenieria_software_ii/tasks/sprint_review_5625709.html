      Process Usage
      • BasicProcess  >  Sprint  >  Sprint Review
      Main Description

      El equipo muestra el incremento funcionando. Si la arquitectura cambio, se muestra la seccion actualizada del SAD y el diagrama C4 correspondiente. Los stakeholders dan feedback que alimenta el backlog.
      Key Considerations
      La review es informal: no hay PowerPoint. La demo es del software. El SAD es parte de la demo cuando corresponde.
