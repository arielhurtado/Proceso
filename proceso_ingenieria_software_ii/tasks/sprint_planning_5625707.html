Task: Sprint Planning
Define el Sprint Goal y selecciona items del backlog.
Disciplines: Gestion
Purpose
Comprometer un conjunto realista de trabajo para el Sprint.
Relationships
RolesPrimary Performer:
  • Equipo de Desarrollo
Additional Performers:
  • Product Owner
  • Scrum Master
InputsMandatory:
  • Product Backlog
    		Optional:
    • Software Architecture Document (SAD)
      Outputs
      • Sprint Backlog
      • Sprint Goal
        Process Usage
        • BasicProcess  >  Sprint  >  Sprint Planning
        Main Description

        Parte 1 (Que): el PO presenta los items de mayor prioridad; el equipo pregunta y refina; se define el Sprint Goal.

        Parte 2 (Como): el equipo descompone las historias en tareas y se autoasigna. Si hay incertidumbre arquitectonica, se crea una tarea de Spike Arquitectonico (timeboxed).
        Key Considerations
        Involucrar al Arquitecto en la seleccion de historias con impacto en la arquitectura. Reservar capacidad para deuda tecnica y evolucion del SAD.
