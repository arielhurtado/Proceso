Description
Main Description

El SAD es un artefacto incremental. No se escribe una vez al final. En cada Sprint, si una historia impacta la arquitectura, se actualiza la seccion correspondiente y se versiona en el repositorio (formato Markdown + diagramas como codigo, ej. Mermaid/PlantUML).
